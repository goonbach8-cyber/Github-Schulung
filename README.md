# GitHub Schulung

Interaktive Ausbildungssequenz zu GitHub für Modul 219.

## Technik

- React
- TypeScript
- Vite
- CSS
- GitHub Actions
- GitHub Pages

## Lokal starten

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Die Website ist für GitHub Pages vorbereitet. In den Repository-Einstellungen unter **Settings → Pages** muss als Source **GitHub Actions** gewählt werden.
